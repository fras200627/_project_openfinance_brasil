**************************************************************************************************
Step 01: Install Linux on WSL
**************************************************************************************************
Open Terminal Window with Administrator Option
Next, execute commands below::
wsl --install Ubuntu-22.04 (ex: wsl --install Ubuntu-24.04. Use command wsl -l -o to view linux distros)
Next step: 
    create a root user
    user: tican
    password: tican
Next step: 
    modify user to sudo user:
    sudo -s
Next step: 
    create access to developement folders:
    chmod 0777 /mnt/c/_development/__projects/ -R

**************************************************************************************************
Step 02: Configure alias linux commands
**************************************************************************************************
Open command:
    nano ~/.bashrc

ADD LINES 
    alias k8s='microk8s kubectl'
    alias kubectl='microk8s kubectl'
    alias wsl_path='cd /mnt/c/_development/__projects/__wsl/'
    alias wsl_open='cd /mnt/c/_development/__projects/_project_tican_openapi/__wsl/'

Refresh command:
    source ~/.bashrc

**************************************************************************************************
Step 03: Update/Upgrade all Linux add-ons  
**************************************************************************************************
Command:
    wsl_open
Command:
    cd ./0-wsl_env_create
Command:
    sh ./1.ubuntu_config.sh

After, execute a Refresh Linux
Command:
    exit
    wsl --shutdown
    wsl -d Ubuntu-22.04
    execute login
    change to sudo user: sudo -s

**************************************************************************************************
Step 04: Install and Configure a Docker environment  
**************************************************************************************************
Command:
    wsl_open
Command:
    cd ./0-wsl_env_create
Command:
    sh ./2.docker_install.sh
Command:
    apt -y update
    apt -y upgrade
    
After, execute docker verify status
    docker info
    systemctl status docker
