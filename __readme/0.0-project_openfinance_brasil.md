>## Project Open Finance Brasil 2025
> ###### return to index? [click here...](0.0-index.md)

---
> #### Summary
This project was developed to study technologies for building APIs, Orchestrators, Listeners, Batches and libraries, based on existing processing flows in **[Open Finance Brasil](https://www.bcb.gov.br/estabilidadefinanceira/openfinance).**

---
> #### Project Scope
**Only 4 flows from OFB were used, specifically the 4 main ones:**
* [Resources](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/17369706/DC+API+-+Recursos)
* [Consents](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/17369335/DC+API+-+Consentimento)
* [Customers](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/17370003/DC+API+-+Dados+Cadastrais)
* [Accounts](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/pages/17371726/DC+API+-+Contas)

The flows above were built with all the services described in **[Official documentation site for the development of the OFB](https://openfinancebrasil.atlassian.net/wiki/spaces/OF/overview)** and
are present in the orchestrators and services of the backend APIs.

> #### Project Structure - Modules
1. **Managment/Security Services**
   * Discovery Services
   * API Gateway
   * Authentication Server
   * Authorization Server
2. **OFB Services**
   * Consents
   * Customers
   * Accounts
   * Resources
3. **OFB Extend Services**
   * Participants Clients (simulation of Participants Directory)
   * Audit Tracking
   * Audit Authorization Consents
   * Audit Cancellation Consents
   * Audit Extends Consents
   * Audit Revoked Consents
5. **Listeners Services**
    * Audit Services
    * Consents Authorization Services
    * Consents Cancellation Services
6. **Batches Services**
    * Consents Approval Control
    * Consents Expiration Control
