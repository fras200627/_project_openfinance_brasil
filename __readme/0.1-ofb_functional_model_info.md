Mode: Basic Auth (Client Credentials is valid)

O Participante deve ter data de expiração válida. (client_secret_expires_at)
* O client token gerado tem validade de 30 minutos.

Process 02: Get Access Token
Mode: Bearer Token is valid
Verify a expiration DateTime

        - Validade Anual (data hoje + 12 meses e horário 23:59:59)
