Authentication - Acesso ao PostConsents
Schema: user
Table:  oauth2_registered_client

---------------------------------------------------------------------------------
Process 01: Get ClientToken
Mode: Basic Auth (Client Credentials is valid)
O Participante deve estar ATIVO e DESBLOQUEADO (status: ACTIVE, LOCKED, INACTIVE)
O Participante deve ter data de expiração válida. (client_secret_expires_at)
* O client token gerado tem validade de 30 minutos.

Process 02: Get Access Token
Mode: Bearer Token is valid
Verify a expiration DateTime

Passo 03: Verificação do Particpante (client.document):
Validação do Token: clientToken é baseado no cadastro de participantes (clients.business)
Database: MySQL or Client Business API
    O Parcipente existe na base de participantes ?
    O Participante deve estar ATIVO e DESBLOQUEADO (status: ACTIVE, LOCKED, INACTIVE)
    O Participante deve ter data de expiração válida. (client_secret_expires_at)
    O Participanente possui as roles necessarias: client.ofb.read e client.ofb.write?

Passo 04: Verificação do Client (customer.document)
Database: Oracle or Customers API
    Customer existe na base de customers ?
    Customer está ativo e desbloqueado?

Passo 05: Verificação do Consentimento (ofb.consent.id)
Database: Oracle or ConsentsAPI
    Consentimento existe na base de consentimentos?
